## ✅ Tasks Overview

### Task 1 — Calculator
A fully functional browser-based calculator with a CSS Grid button layout, operator chaining (e.g. `5 + 3 × 2`), backspace, clear, and division-by-zero handling. Built without `eval()` — arithmetic logic is handled manually with `parseFloat()` and conditional statements.
**Tech:** HTML5, CSS3, Vanilla JavaScript
📂 [`Firaol_Task1/`](./Firaol_Task1)

### Task 2 — Tribute Page
A tribute page for Marie Curie, combining an original, researched biography (paraphrased from Britannica and the Nobel Prize archives), a milestone timeline, and a styled quote block.
**Tech:** HTML5, CSS3
📂 [`Firaol_Task2/`](./Firaol_Task2)

### Task 3 — To-Do Web App
An interactive to-do list with add, edit, complete, and delete functionality, split into Pending and Completed lists with live counters, timestamps, and full persistence via `localStorage`.
**Tech:** HTML5, CSS3, Vanilla JavaScript
📂 [`Firaol_Task3/`](./Firaol_Task3)

### Task 4 — Authentication System
A front-end authentication flow: registration with password validation and duplicate checking, login with generic error handling, a protected dashboard that redirects unauthenticated visitors, and logout. Passwords are hashed with SHA-256 (Web Crypto API) rather than stored in plain text.
**Tech:** HTML5, CSS3, Vanilla JavaScript, `localStorage`
📂 [`Firaol_Task4/`](./Firaol_Task4)
