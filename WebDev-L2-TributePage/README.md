# Tribute Page: Marie Curie – OIBSIP Task 2

A tribute page dedicated to Marie Curie, built for the Oasis Infobyte Web Development Internship (Task 2).

## Live Demo

Not deployed — the project runs locally by opening `index.html` in a modern web browser.

## Tech Stack

* HTML5
* CSS3
* CSS Grid and Flexbox
* Responsive media queries
* Google Fonts

## Sources

Biographical information was researched using Britannica and Nobel Prize resources and rewritten in original words.

Portrait:
Henri Manuel, c. 1920, public domain, via Wikimedia Commons.
